Git

  • git init - создаёт новый локальный репозиторий в текущей папке.
  • git add - добавляет в индекс все изменённые файлы в текущей директории..
  • git commit -m "сообщение" - создаёт коммит с указанным сообщением.
  • git status - показывает состояние рабочей директории и индекса: какие файлы изменены, какие добавлены, какие ещё не отслеживаются.
  • git log - выводит историю коммитов текущей ветки.
  • git push - отправляет локальные коммиты в удалённый репозиторий.
  • git pull - забирает изменения из удалённого репозитория и объединяет их с текущей веткой.
  • git clone - клонирует удалённый репозиторий на локальный компьютер.
